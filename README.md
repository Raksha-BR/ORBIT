# ORBIT

**ORBIT** is an intelligent job-search and application engine that discovers,
analyzes, matches, automates, and learns from job applications.

## Vision

ORBIT aims to reduce the repetitive work involved in modern job hunting by
automating job discovery, job analysis, candidate matching, application
preparation, application workflows, and application tracking.

## Core Lifecycle

Discover → Understand → Match → Prepare → Apply → Track → Learn

## Technology Direction

- AI / ML
- Browser Automation
- Distributed Systems
- Databases
- Linux
- Docker
- Observability
